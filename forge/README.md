# Forge

Forge is a local-first focus timer. Its focus and break timers, preferences, and completed focus sessions are stored in this browser; no account or API key is needed.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Features

- Focus, short-break, and long-break timers with timestamp-based countdown and reload recovery.
- Quick focus-duration presets, custom duration, pause, resume, and reset.
- A gentle, locally generated completion chime, with a sound toggle in settings.
- Daily focus time, completed sessions, a current streak, and a compact seven-day activity view.
- Settings for timer durations, completion sound, and opt-in browser notifications.
- Locally stored settings and focus-session history; no account or external audio assets.
